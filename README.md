# Edu-Generation AI Platformasi

Edu-Generation - bu o'qituvchilar va talabalar uchun sun'iy intellektga asoslangan zamonaviy ta'lim platformasi. Ushbu platforma orqali dars ishlanmalari, slaydlar, testlar va tasvirlarni soniyalar ichida yaratish mumkin.

## 🚀 Asosiy Imkoniyatlar

*   **AI Slayd Generator:** Har qanday mavzuda professional prezentatsiyalar yaratish.
*   **AI Tasvir Generator:** Mavzuga oid kreativ va ta'limiy rasmlar yaratish.
*   **AI Test Generator:** O'quvchilar bilimini tekshirish uchun avtomatik savollar bazasini shakllantirish.
*   **Suhbatdosh (Chat):** Fanlar bo'yicha murakkab savollarga javob olish.
*   **Hamjamiyat (Feed):** Yaratilgan ishlarni boshqalar bilan ulashish va yuklab olish.

## 🛠 Texnologik Stek

### Frontend:
*   **React 19** - Foydalanuvchi interfeysi.
*   **Vite** - Tezkor yig'uvchi (Build tool).
*   **Tailwind CSS** - Zamonaviy dizayn.
*   **Framer Motion** - Dinamik animatsiyalar.
*   **Lucide React** - Ikonkalar to'plami.

### Backend:
*   **Django (Python)** - Asosiy mantiq va API.
*   **SQLite** - Ma'lumotlar bazasi.
*   **Firebase Auth** - Google orqali tizimga kirish.
*   **Gemini 2.0 Flash API** - Sun'iy intellekt modellari.

## 📦 O'rnatish va Ishga tushirish

### 1. Reperozitariyni nusxalash:
```bash
git clone https://github.com/sizning-repo/edu-generation.git
cd edu-generation
```

### 2. Frontend-ni ishga tushirish:
```bash
npm install
npm run dev
```
Frontend odatda `http://localhost:3000` manzilida ochiladi.

### 3. Backend-ni ishga tushirish:
```bash
cd backend
python -m venv venv
source venv/bin/activate  # Windows uchun: venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
Backend odatda `http://localhost:8000` manzilida ochiladi.

## 🌍 Hamjamiyat bilan ishlash
Platformaning "Hamjamiyat ishlari" bo'limida siz:
1.  Barcha ochiq resurslarni ko'rishingiz mumkin.
2.  O'zingiz yaratgan ishlarni "Mening ishlarim" bo'limida ko'rishingiz mumkin.
3.  **"Hamjamiyatga chiqarish"** tugmasi orqali o'z ishlaringizni boshqalar ko'rishi uchun ochishingiz mumkin.
4.  Istalgan ishni PDF yoki PPTX formatida yuklab olishingiz mumkin.
